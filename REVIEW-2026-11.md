## 3. Things to know before going live

1. **The live domain name is still attached to the old system.** CloudFront
   will not let two distributions share `hottub.cohoecovillage.org`. Deploy
   live with `--no-domain` first, and add the name at cut-over, after removing
   it from the old distribution.
2. **SES starts in "sandbox" mode** in an AWS account that has not used it: it
   only delivers to addresses that have themselves been verified. Production
   access is requested in the SES console and AWS usually answers within a day.
   Until then, leave SES off and use Cognito's sender.
3. **Only one controller may manage the tub at a time.** While the old
   `bwa_aws_iot_thing` is running, start the new operator with
   `--report-only`; otherwise each treats the other's changes as someone
   pressing buttons on the tub.
4. **The first admin is created from the command line**:
   `python scripts/manage_users.py create live you@example.com --admin`.
   After that, everything is done in the Users tab.

rights are checked against Cognito on every admin request, not read from the
token, so revoking them is immediate; the operator key is visible to anyone who
can view the Lambda's configuration in the AWS account; a removed user's
existing token keeps working for up to 60 minutes (accepted).
